Native, not only web

SwiftUI and Compose code is scanned and scored like CSS: literals in views, emoji, greetings, stock-kit colors, rows of stat cards.

One fix at a time, and nothing changes until you say yes

  1. Review

    Five numbered fixes for the screen, each with its reason and its checklist number. Hierarchy and spacing before color.

  2. Before/after

    Both versions on one page at the same width. Nothing in your code moves until you approve it.

  3. Apply and measure

    Each fix lands as a token, not a literal. The score runs again and the PR says “score 41 → 88”.

What it catches

72 fixes in the checklist, and a scanner with 48 rules that reads web, SwiftUI and Compose code. A few:

#19
One accentThe brand color fills one gesture, not every badge and icon.
#26
A title, not a greeting“November budget”, not “Hey Alex!”.
#55
No gradient text, no page glowHeadlines in the ink color.
#64
Nothing inventedNo user counts, ratings or logos without a source.
#65
A skeleton from the jobNot greeting, stat card, 2×2 tiles, list, tab bar.
#68
One separator per surfaceA border or a shadow, not both on every card.
#71
Every language, every size of dataPlurals from the platform, never “item(s)”.
P5
Measured contrastWCAG AA from the real colors, light and dark.

It keeps working after the review

  • In Claude Code, a hook scans every UI file the agent edits and tells it what slop it just added. Silent when clean.
  • On GitHub, the action annotates each line, keeps one PR comment with the score and the change against the base branch, and fails under your minimum.
  • .unslop/context.md keeps your scales and decisions, so a base-6 grid or a brand face isn’t flagged twice.
  • Native first: SwiftUI and Compose are scanned, not only web.
# .github/workflows/unslop.yml
on: pull_request
permissions:
  contents: read
  pull-requests: write
jobs:
  unslop:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - uses: marcosnovo/unslop-design@v1.12.0
        with:
          paths: src
          min: 80
